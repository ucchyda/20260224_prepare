# SmartHR想定ダミーデータセット（v1）

このフォルダは、取締役会アシストAgent検証用の SmartHR 想定データを1か所に集約したものです。

## フォルダ構成
- `finance/` : 財務諸表・資金繰り・予実・資本政策
- `org/` : 組織図・RACI・人員
- `operations/` : SLA/障害・再現性指標
- `product/` : プロダクトロードマップ
- `compliance/` : 監査指摘・提携契約条件
- `public/` : 公開情報（ニュース・外部シグナル）
- `sales/` : 顧客KPI・ARR/NRR/解約
- `meta/` : カタログ・evidence管理
- `golden_cases/` : Golden-case（SMの想定検証ケース）
- `runbook/` : SM向けシナリオ
- `meetings/` : SmartHR取締役会議事録（`smarthr-2026-01-02/`）
